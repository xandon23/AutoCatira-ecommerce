# Persona e conexão com o cliente

## Persona principal: Marcos, o comprador que quer trocar de carro

| | |
|---|---|
| **Perfil** | 34 anos, técnico de manutenção, mora em Campo Mourão (PR), casado, um filho pequeno. |
| **Situação** | Tem um Gol 2015 quitado e quer um carro mais novo e espaçoso. Não tem o valor total em dinheiro: pretende **dar o Gol como parte do pagamento** e completar a diferença. |
| **Como busca hoje** | Grupos de Facebook, OLX e WhatsApp. Precisa perguntar anúncio por anúncio se o vendedor "aceita troca", e a negociação se perde em várias conversas. |
| **Dores** | Não sabe se o vendedor aceita troca. Repete a mesma oferta para vários vendedores. Não tem registro do que foi proposto. Tem receio de expor o telefone para desconhecidos. Não confia em vendedores sem histórico. |
| **Objetivo** | Fazer ofertas claras (valor + carro na troca), acompanhar as respostas num só lugar e fechar negócio com alguém confiável. |
| **Uso de tecnologia** | Usa o celular para tudo; pouco uso de computador. |

## Persona secundária: Juliana, a vendedora

| | |
|---|---|
| **Perfil** | 41 anos, revende alguns carros por ano como renda extra. |
| **Dores** | Recebe muitas mensagens soltas, perde propostas no meio das conversas e não consegue comparar ofertas que envolvem troca. Depois de vender, continua recebendo propostas pelo carro. |
| **Objetivo** | Ver todas as propostas de cada anúncio organizadas, escolher com quem negociar e encerrar o anúncio quando vender. |

## Como o AutoCatira atende as personas

| Dor | Solução no AutoCatira |
|---|---|
| "Não sei se aceita troca" / repetir a oferta | **Proposta estruturada:** valor em dinheiro + veículo do próprio comprador na troca, enviada pelo app. |
| Negociação espalhada em conversas | **Telas de propostas enviadas e recebidas**, com status (pendente, em negociação, aceita, recusada). |
| Receio de expor o telefone | **Privacidade:** o contato só é liberado quando o vendedor aceita negociar. |
| Comparar ofertas com troca | O vendedor vê, por anúncio, cada proposta com o valor e o veículo oferecido (com fotos). |
| Continuar recebendo propostas após vender | **Venda pelo sistema:** o carro sai do ar e todas as outras propostas, inclusive as que envolvem o carro da troca, são recusadas automaticamente. |
| Desconfiança | **Avaliações** entre comprador e vendedor após cada venda. |
| Usa só o celular | **App mobile** como cliente principal. |
